# The Ω42 forum (GitHub Discussions)

The forum is the repository's **Discussions** tab. Anyone with a GitHub account can post; anyone can read without one.

| Category | For | Form |
|---|---|---|
| **Announcements** | Releases, newsletter issues, Committee news (maintainers post; everyone can reply) | — |
| **Ideas** | New instruments, lenses, applications, features | `ideas.yml` |
| **Debate** | Arguments for and against a claim, a reading or a design choice | `debate.yml` |
| **Readings** | Discussing a published navigation: what it opened, where it fell short | `readings.yml` |
| **Professional Opinions** | Verified professionals' assessments in their field | `professional-opinions.yml` |
| **Research Areas** | One thread per area in `research/`, for coordination | — |
| **Q&A** | Questions about using the protocol, with answers marked | `q-a.yml` |
| **Protocol Revisions** | Proposed changes, discussed for 14 days before a vote (GOVERNANCE.md §5) | `protocol-revisions.yml` |
| **Governance** | The Committee, elections, policies | — |
| **Show and Tell** | Apps, art, music, teaching built on Ω42 | — |

**Debate format.** A *Debate* post states one claim, the case for it, and what would change the poster's mind. Replies that argue the opposite are labelled *Counter*; replies that add evidence are labelled *Evidence*. Each month the Committee picks one debate for a written summary in the newsletter.

**Professional Opinions.** A post here carries the author's registry number from `community/professionals.json`. Posts without a number are moved to *Debate*. A professional speaks for themselves, not for their employer or the project.

**Moderators** are listed here when appointed. The Code of Conduct applies.
