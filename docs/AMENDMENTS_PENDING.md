## CA-04: Construct prediction mechanism (Appendix S)
- The Construct's 23 lag templates (past draw → Field Y → copy-linked Field X → predicted draw) are recorded as the historical prediction mechanism of the precursor.
- For uniform, independent draws, every rule built from past draws has the same expected match count, k²/N (0.735 for 6-of-49). No template choice changes that mean.
- Selecting the best of 23 templates on past data manufactures apparent signal. On 3,000 simulated random draws, `tools/construct_backtest.py` finds a "best" template at z = +2.53. That template matches nothing real, because the draws were random by construction.
- Rule: a template counts as signal only if it beats k²/N on draws recorded after the template is sealed, at the Bonferroni-corrected bar (z > 3.06 for 23 templates). Real-money use stays barred (L-300).
- Ω42 navigation does not use the draw-prediction mechanism. The Construct's lasting contribution is its geometry (CA-03), not its forecasts.

## CA-08: Speculation Test Protocol (STP) — formal part of operations
1. Every speculation the Navigator offers states its hypothesis and how it could fail.
2. If testable, it is entered in `docs/SPECULATION_REGISTER.md` with an ID, a test procedure and a pass/fail criterion fixed before the test runs.
3. If the data is at hand, the test runs in the same session and the result is reported in the reply; otherwise the entry stays UNPROVEN with its test plan.
4. A partial result is split into sub-hypotheses; failures are filed REJECTED and kept.
5. A speculation with no possible test is labeled INTERPRETIVE (CDT-C) and stays speculation.
6. In the reply, each speculation ends with: `Test: <ID> | Status: <status>`.
First run (18 November 2026): H-001 and H-005 VERIFIED; H-002, H-003, H-004 REJECTED; Construct X seed labelling corrected (N6↔P3, N3↔P6).
