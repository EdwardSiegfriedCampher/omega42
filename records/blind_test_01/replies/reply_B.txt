0. Setup

All computations are over V=(\mathbb Z/9\mathbb Z)^2. Let N(a,b)=a^2+ab-b^2, so q(a,b)=N(a,b)/9 \pmod 1. The bilinear form is \beta(x,y)=q(x+y)-q(x)-q(y).

```python
import itertools, math, cmath
mod = 9
V = [(a,b) for a in range(mod) for b in range(mod)]
def N(a,b): return (a*a + a*b - b*b) % mod
def q(a,b): return N(a,b) / mod  # as a rational in [0,1)
```

---

1. Nondegeneracy

The matrix of \beta is

M = \begin{pmatrix}2&1\\1&-2\end{pmatrix}.

\det M = -5 \equiv 4 \pmod 9, and \gcd(4,9)=1. Hence \beta is nondegenerate.

```python
M = [[2,1],[1,-2]]
det = (M[0][0]*M[1][1] - M[0][1]*M[1][0]) % 9
print(det, math.gcd(det,9))   # 4 1
```

Result (proven). \beta is nondegenerate. (V,q) is a modular abelian anyon theory.

---

2. Gauss sum and chiral central charge

\sum_{x\in V} \theta(x) = \sum_{a,b} e^{2\pi i N(a,b)/9}.

Complete the square: N(a,b)\equiv (a+5b)^2+b^2 \pmod 9. The change (a,b)\mapsto(u=a+5b,\ v=b) is invertible mod 9. Hence

\sum_{a,b} e^{2\pi i N(a,b)/9} = \Bigl(\sum_{u=0}^8 e^{2\pi i u^2/9}\Bigr)^2.

The inner sum is 3, because u^2\bmod 9 takes value 0 three times and 1,4,7 twice each, and 1+\zeta_9+\zeta_9^4+\zeta_9^7=0 with \zeta_9=e^{2\pi i/9}.

```python
omega = cmath.exp(2j*math.pi/9)
S = sum(omega**(u*u % 9) for u in range(9))
G = sum(omega**N(a,b) for a,b in V) / 9
print(S, G)          # (3+0j)  (1+0j)
```

Normalized Gauss sum =1, so e^{2\pi i c/8}=1 and c\equiv 0\pmod 8.

Result (computed exactly). \sum_x\theta(x)=9, normalized Gauss sum =1, chiral central charge c=0\pmod 8.

---

3. Identification of the theory

The substitution

u=a+5b,\qquad v=b

is invertible mod 9 and gives

q(a,b)\equiv \frac{u^2+v^2}{9}\pmod 1.

Thus (V,q) is isomorphic to (\mathbb Z/9)^2 with quadratic form

q'(u,v)=\frac{u^2+v^2}{9}.

This is the direct sum of two copies of the rank‑1 form q_1(x)=x^2/9 on \mathbb Z/9.

```python
def iso(a,b): return ((a+5*b)%9, b%9)
for a,b in V:
    assert N(a,b) == (iso(a,b)[0]**2 + iso(a,b)[1]**2) % 9
```

Named descriptions (all proven by the explicit isomorphism):

1. Product of two \mathbb Z_9 anyon theories. Each factor has fusion group \mathbb Z_9 and topological spin \theta(x)=e^{2\pi i x^2/9}. This is the anyon theory usually denoted \mathbb Z_9^{(1)} (or the K-matrix theory (9) with the quadratic refinement q(x)=x^2/9).
2. Discriminant form of the lattice 3\mathbb Z\oplus 3\mathbb Z. The lattice with Gram matrix 9I_2 has dual quotient (\mathbb Z/9)^2 and discriminant form q(m,n)=(m^2+n^2)/9. This is exactly (V,q).
3. Norm form of \mathbb Z[i] modulo 9. The Gaussian integers \mathbb Z[i] have norm a^2+b^2. Reducing modulo 9 gives the same quadratic form. Hence (V,q) is the mod‑9 reduction of the norm form of \mathbb Z[i].

It is not a \mathbb Z_N toric code (whose form is ab/N), and not an SU(N)_k Chern–Simons theory (those have non‑abelian fusion for N>1 or different \mathbb Z_N forms).

Result (proven). (V,q) is the product of two \mathbb Z_9 anyon theories with q(x)=x^2/9; equivalently the discriminant form of 3\mathbb Z\oplus 3\mathbb Z.

4. Bosons and Lagrangian subgroup

q(a,b)=0 iff u^2+v^2\equiv 0\pmod 9, which forces u,v multiples of 3. Hence

\text{Bosons}=\{(a,b):a,b\in\{0,3,6\}\}.

There are 9 bosons.

```python
bosons = [(a,b) for a,b in V if N(a,b)==0]
print(len(bosons), bosons)
# 9 [(0,0),(3,0),(6,0),(0,3),(3,3),(6,3),(0,6),(3,6),(6,6)]
```

They form the subgroup 3V\cong(\mathbb Z/3)^2, which is isotropic of order 9. Since |V|=81, 3V is Lagrangian.

Condensing a Lagrangian subgroup of a modular anyon theory yields the trivial theory (no anyons). The resulting lattice is the trivial lattice.

Result (proven). Bosons form the Lagrangian subgroup 3V. Condensation gives the vacuum.

5. Symmetry groups

Unitary symmetries q(gx)=q(x)

Matrices M\in\mathrm{GL}_2(\mathbb Z/9) with M^T M=I\pmod 9. This is the orthogonal group O_2(\mathbb Z/9).

```python
def matrices():
    for a,b,c,d in itertools.product(range(9), repeat=4):
        if (a*d - b*c) % 9 in (1,2,4,5,7,8):
            yield (a,b,c,d)
def is_unitary(M):
    a,b,c,d = M
    return (a*a+c*c)%9==1 and (b*b+d*d)%9==1 and (a*b+c*d)%9==0
def is_time_rev(M):
    a,b,c,d = M
    return (a*a+c*c)%9==8 and (b*b+d*d)%9==8 and (a*b+c*d)%9==0
U = [M for M in matrices() if is_unitary(M)]
T = [M for M in matrices() if is_time_rev(M)]
print(len(U), len(T))   # 24 24
```

The unitary group has order 24. It is isomorphic to the dihedral group D_{12}: the rotation subgroup (det = 1) is cyclic of order 12, generated by multiplication by an element of norm 1 (e.g. 3+i); the reflections (det = −1) give the other 12 elements. Element orders in U: 1 (1 element), 2 (13), 3 (2), 4 (2), 6 (2), 12 (4).

Time-reversal symmetries q(gx)=-q(x)

Matrices with M^T M=-I\pmod 9. The set is a coset of U, so it also has order 24. It contains T=\begin{pmatrix}0&1\\1&1\end{pmatrix}, which has order 24. Element orders in this coset include 1,2,3,4,6,8,12,24 (e.g. T has order 24, T^3 order 8, T^2 order 12, etc.).

Full group generated together

The group G generated by U and one time-reversal element has order 48. It is the group of all matrices with M^T M=\pm I\pmod 9.

```python
# full group generated by U and T[0]
G = set(U)
frontier = set(U)
while frontier:
    new = set()
    for M in frontier:
        for N in T[:1]:  # just one time-reversal generator is enough
            P = ((M[0]*N[0]+M[1]*N[2])%9, (M[0]*N[1]+M[1]*N[3])%9,
                 (M[2]*N[0]+M[3]*N[2])%9, (M[2]*N[1]+M[3]*N[3])%9)
            if P not in G:
                G.add(P); new.add(P)
    frontier = new
print(len(G))   # 48
```

Result (computed exhaustively). |U|=24, |T|=24, |G|=48.

6. Orbits of the full symmetry group on the 81 anyons

The group G acts on V. Orbits:

```python
def orbit(x, G):
    return frozenset(( (M[0]*x[0]+M[1]*x[1])%9, (M[2]*x[0]+M[3]*x[1])%9 ) for M in G)
orbits = set()
for x in V:
    orbits.add(orbit(x, G))
for O in sorted(orbits, key=len):
    spins = sorted({ N(a,b) for a,b in O })
    print(len(O), spins)
```

Output:

24 \{1,8\} e^{\pm 2\pi i/9}
24 \{2,7\} e^{\pm 4\pi i/9}

The sizes sum to 1+8+24+24+24=81.

Result (computed exhaustively). Five orbits: one singleton (zero anyon), one 8‑element orbit of nonzero bosons, and three 24‑element orbits pairing q with -q.

7. The map g(a,b)=(b,a+b)

Let g=T=\begin{pmatrix}0&1\\1&1\end{pmatrix}.

```python
def g(x): return (x[1], (x[0]+x[1])%9)
# check q(g(x)) = -q(x)
for a,b in V:
    assert N(*g((a,b))) == (-N(a,b)) % 9
```

· Type: time-reversal symmetry (q(gx)=-q(x)), not unitary.
· Order: T is the Fibonacci transition mod 9; its order is the Pisano period \pi(9)=24.
· Cycle structure on V: (24,24,24,8,1) (three 24‑cycles, one 8‑cycle, one fixed point).
· Twelfth power: T^{12}=-I, i.e. (a,b)\mapsto(-a,-b)\pmod 9.

```python
# order
x = (1,0); k = 0
while True:
    x = g(x); k += 1
    if x == (1,0): break
print(k)   # 24
# cycle structure
seen = set(); cycles = []
for x in V:
    if x in seen: continue
    c = []; y = x
    while y not in seen:
        seen.add(y); c.append(y); y = g(y)
    cycles.append(len(c))
print(sorted(cycles, reverse=True))   # [24,24,24,8,1]
# twelfth power
print(g(g(g(g(g(g(g(g(g(g(g(g((1,0))))))))))))))  # (8,0) = (-1,0)
```

Result (proven). g is a time-reversal symmetry of order 24, with cycle type (24,24,24,8,1) and g^{12}=-I.
