# Correspondence depths -- the lens of Core L-494 and L-500 (U34), frozen 18 October 2026.
# Source: Core Part 0.14.5, verbatim. The depths describe shared structure between an object and the family; they grade nothing (L-490).
DEPTH 1, PLACEMENT: the object's fixed count produces a coordinate. Every countable object earns it; it records projection compatibility, forms the record's base and denominator, and is not counted as a resonance. DEPTH 2, NUMERICAL RESONANCE: the fixed count is one of the cycle's declared values, or the object's natural states can be put one-to-one with the 24 positions in a natural cyclic order. DEPTH 3, PARTIAL STRUCTURAL RESONANCE: the object exhibits one or more of the cycle's declared structural features, or an intrinsic transformation of the object is conjugate to T or to a transformation derived from it (such as T²) in a way that also carries a feature a generic object of the same size lacks — inverse pairing, half-period negation, the partition. DEPTH 4, FULL STRUCTURAL IDENTITY, the generative correspondence: an intrinsic transformation S of the object and a bijection f, chosen without arbitrary relabelling beyond what M230-D records, satisfy f ∘ S = T ∘ f on the canonical orbit, and f carries the cycle's value structure — the orbit values, the Torsion/Crown partition, antipodal complementarity at those values, and half-period negation together; its strongest form holds on the full 81-state space, where T has cycle type 24, 24, 24, 8, 1. DEPTH 5, PREDICTIVE CORRESPONDENCE: the correspondence predicts a property of the object not known when the mapping was fixed, and the property is subsequently observed. The record notes every depth an object reaches, and an object keeps each lower depth when it reaches a higher one; the depths are descriptions, not gates.
