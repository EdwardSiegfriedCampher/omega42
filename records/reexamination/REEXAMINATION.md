V335 Rev.450 STABLE · 16 October 2026 · Navigator: claude-opus-5-5 (Anthropic; serving model may differ) · Originator: ESC

Ω42 does not defer to the scientific method. It accommodates it (Core L-491). This file re-reads every investigation
recorded before that principle was written. Each one is read under **the question it was designed to answer**, in **its own
jurisdiction**, and nothing more is drawn from it.

**How this re-reading works**

- **Frozen records are not edited.** Their text, hashes and freezes stand as issued. The re-reading changes how a record
  is *described*, never what it *found* (L-411).
- **One question per record.** Each entry gives the record, the question, the jurisdiction (Core Part 0.0.3 item 3, Part 0.0.4
  item 5), what was found within scope, the words the frozen record used, how those words read now, what the record does
  not decide, and what is open.
- **No entry is a status of Ω42.** The premise carries no tier (L-490). Nothing here is counted as a validation, and an
  investigation not yet undertaken is never an internal defect (L-491).
- **Record integrity (L-490 item 7).** Source: the files named in each entry. Specification: V335 Rev.450 STABLE. What is
  counted: investigations recorded in `records/` and `examples/corpus/` up to 16 October 2026. Criterion: an entry exists for
  every investigation record (`tools/reexamine.py --check`).

| A frozen record says | Read it now as |
|---|---|

| Support Standard, SUPPORT-PARTIAL, SUPPORT-STRUCTURAL | Congruence Profile — which of the features S1–S8 the object shows |

| evidence, evidence-bearing | observation, agreement-bearing measurement |
| EMERGING, SUPPORTED, WELL-SUPPORTED, CONFIRMED, REFUTED | the breadth of the Convergence Record (INITIAL, BROAD, EXTENSIVE, DIVERGENT, INCONCLUSIVE) — of the mechanism's execution, never of Ω42 |
| Empirical Confidence Index | Reproduction Count |
| Falsifiability Test (M116) | Perturbation Test |
| "stress test" (M267) | decoy comparison |
| "test the premise", "support the premise" | not available: no measure grades the premise (L-490) |

Instrument tiers (Tier 1, 2, 3 instruments) and the CDT classes are a different thing. They say when an instrument runs
and how a statement is classified, and they are unchanged.
