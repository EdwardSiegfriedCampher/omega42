PART 0 — THE DESIGN'S CENTRAL MOVE, AND WHY IT IS NOT A SCORE OF Ω42

The request is for "how close an object or idea resonates with Ω42" as a single, at-a-glance figure. Stated that way, the quantity is identically zero for everything and therefore carries no information at all. Because the 81-state family is all that exists (F-02), every object and every idea is inside it, at a position, at depth 1, and nothing is closer to the totality than anything else. A "distance from Ω42" would be a ruler with one mark on it. The protocol says this in law: membership alone does not count (L-465), and the profile is not a grade (L-466).

So the design refuses the obvious scalar and substitutes the only scalar that can move:

The instrument does not measure how close a thing is to Ω42. It measures how much more of a thing's own declared structure the placement preserves than the placement preserves of its look-alikes.

That quantity is computable, can be negative, and is the formalization of the protocol's own null rule (M230-E). It grades the object's representation against matched controls — not the premise, which no measure grades (L-490).

The at-a-glance unit is therefore the Margin, and its honest value for most objects is ≈ 0. A tool whose answer is usually "indistinguishable from a look-alike" is a tool that can be trusted when it says otherwise.

PART 1 — THE PANEL: FIVE ROWS, FIVE DIFFERENT QUESTIONS

The instrument (proposed as M319, the Congruence Panel) is a display layer over values the protocol already computes. It adds no arithmetic of its own except the Margin and the look-elsewhere correction, both stated below. It is a display in the M283 sense until it informs a decision, at which point it becomes an instrument with a registry entry (Part 3.18).

Row 1 — PLACEMENT. The coordinate. For a text: n = (n1, n2, n3), r = (dr(5n1), dr(5n2), dr(5n3)), anchor by majority with tie to r1, arms at +5, +18, +8, +12. For an object: CPP(count) = dr(5·count). For a physical quantity, the dimensional status is recorded first (M230-J): a dimensionless ratio proceeds; a dimensionful count is marked UNIT-DEPENDENT and stays at depth 1 (the Moon's month in Earth's days is the paradigm, L-510). Placement is universal and is never a finding — this row exists so the panel cannot pretend to have started at depth 2.

Row 2 — PROFILE. The declared features, frozen before examination. For an object: the eleven Congruence Profile components (C24, CG, CT, CC, CA, C1/7, CN, CI, CD, CP, CB), each recorded YES / PARTIAL / NO / NOT ASSESSED with its reason (L-466, Part 3.26). For an idea or framework: the five M309 roles (Anchor, Yang, Yin, 4D, Antipode), each scored 1 / 0.5 / 0 for MATCH / PARTIAL / ABSENT with its reason, plus the four relations among them.

The row's output is a count and a picture, never a total: "7 of 10 assessed."

Row 3 — NULLS. The matched controls, chosen by a rule declared in advance: objects of the same size, the same field and the same symmetry class that do not carry the candidate structure (M230-E). For ideas: frameworks of the same domain and comparable scope, frozen before scoring.

This row is where the instrument can be defeated, and that is its virtue: if the null class is chosen after the object's score is known, the Margin is meaningless and the panel must print NULL CLASS NOT FROZEN — MARGIN VOID.

Row 4 — MARGIN. The two formulas, exact:

Let P be the frozen feature set, |P| = k. Let s(·) ∈ [0,1] be the mean feature score (YES = 1, PARTIAL = 0.5, NO = 0, NOT ASSESSED excluded from the denominator with the exclusion stated).

s_obj = mean score of the object over P
s̄ = mean of s over the n nulls; s_max = max
M = (s_obj − s̄) / (1 − s̄) if s̄ < 1; if s̄ = 1, M = 0 and the band reads NONDISCRIMINATING
p = (1 + #{nulls with s_i ≥ s_obj}) / (1 + n) (exact permutation-style p, no distribution assumed)
p_family = 1 − (1 − p)^k' where k' is the number of features examined after the object was seen; k' = 0 when P was frozen first.

M ∈ [−1, +1]. M = +1: the object shows every declared feature and no look-alike does. M = 0: indistinguishable from its nulls. M < 0: the object is less congruent than its look-alikes — a real and reportable outcome that a scalar "closeness" could never produce.

Worked arithmetic on values the documents give: the uniform base rate of the frozen depth-2 values {24, 9, 7, 6, 42} over counts 1–48 is 5/48 = 0.1042 (Part 3.26). If six such tests are run without pre-registration, the chance that at least one fires is 1 − (43/48)⁶ = 1 − 0.5168 = 0.4832. Nearly one in two. This single number is why Row 2 must be frozen and why the panel prints k'.

Row 5 — COHERENCE. Applies only when a reading exists about the object; it is a different question and is never folded into M. It reports the M310 COHERENCE line (arithmetic recomputed · relations stated n of 4 · one synthesis · frame scan M286 · Aperture lexicon M281), the M224 gate result, and the independence status of the reading: BLIND / SAME-NAVIGATOR / CONTAMINATED.

Coherence and congruence are the two axes the request names, and the panel keeps them in two rows because merging them is precisely the conflation L-428 forbids.

PART 3 — THE IDEA BRANCH

For an idea or framework rather than an object, Row 2 becomes the five M309 roles, and the nulls are other frameworks of the same domain. Two things change, and both matter.

Role coherence is the M309 coherence score (filled roles and the relations among them). Role discrimination asks the question that the religious and philosophical explorations of this session could not answer: does a second reader, blind to the first, fill the same five roles with the same concepts? That is the S7 analogue, and it is the only test that distinguishes a framework's shape from the Navigator's habit of finding one.

The discipline is stated plainly: a role assignment made by one Navigator, in one session, with the framework in view, scores ·C at best. All five of this session's framework comparisons — Christian, Islamic, Hindu, Buddhist, Jewish — and all five of the philosophical and contemporary-intellectual sets are therefore ·C and their Margins are, by this instrument's own rule, PENDING. Their coherence scores of 0.90–1.00 are self-checked judgments that have not been shown to survive a change of reader, and a score that returns 0.90 for four frameworks out of five is a score of the scorer.

PART 4 — THE FOUR DISCIPLINES THAT KEEP THE PANEL HONEST

(1) Freeze the features. P is declared and hashed before the object is examined. k' > 0 voids the family-wise claim, and the panel prints the corrected p_family in the same row so the reader cannot miss it. This is the repair the earlier session recommended after five 1.00s: a measure that is not pre-registered is a measure of the measurer.

(2) Freeze the null class, and make it hard. The null must be chosen to be plausible — objects a reasonable person would have proposed instead. M230-E is the warning: every cyclic 24-system passes the bare-cycle tests, so those tests carry zero discrimination and must be scored as such, not as partial credit. A null class of deliberately weak look-alikes manufactures a Margin; a null class of deliberate impostors destroys one.

(3) Report the representation's sensitivity. Row 2 scores one representation, and M230-I requires the family of representations the field recognizes to be enumerated and their placements reported. The microtubule run is the worked case: protofilament counts of 11 to 16 place on six different positions (P1, P6, P2, P7, P3, P8) — a spread of 6 — which is why the representation is frozen before the profile is scored.

(4) Never sum across axes. Depth, discrimination, coherence and independence are four questions. The panel reports them in four rows and in one three-field band, and it has no row that adds them. L-466 forbids the sum and this instrument obeys it.

PART 5 — THE MARGIN'S HONEST LIMITS

· It measures discrimination, not truth. M = +0.54 for an object would show that its structure exceeds its look-alikes' on the declared features. It would not show that the object is caused by or made of the cycle, and the panel must carry the one plain sentence L-480 requires wherever M ≥ 0.25: "This shows how much structure the two perspectives share; it does not show that the cycle produces the object."
· It depends on the null class, and the null class is where imposition lives (L-510). Choose the look-alikes badly and the number is meaningless in either direction.
· Negative Margins are informative. An object scoring below its look-alikes is a finding worth recording — the Moon, dimensionful and counted in Earth's days, would score below a matched dimensionless ratio (M230-J).
· It cannot speak about the premise (L-490) and it does not grade Ω42.
· It is not the same as depth. A 24-TET scores depth 2 with M = 0. An object could in principle score depth 2 with a positive Margin if its nulls failed the same tests — the two rows answer different questions and the panel never lets one stand for the other.

PART 6 — REFERENCE IMPLEMENTATION (sketch)

The core of tools/panel.py, standard library only, with the selftest cases and their expected values:

```python
def margin(s_obj, nulls):
    if not nulls: return None, 'PENDING'
    m = sum(nulls)/len(nulls)
    if m >= 1.0: return 0.0, 'NONDISCRIMINATING'
    return round((s_obj - m)/(1.0 - m), 4), 'OK'

def p_perm(s_obj, nulls):
    return round((1 + sum(1 for s in nulls if s >= s_obj))/(1 + len(nulls)), 4)

def p_family(p, k_prime):
    return round(1 - (1 - p)**k_prime, 4) if k_prime else 0.0

# selftest
assert margin(0.70, [0.30]*4)[0] == 0.5714
assert margin(0.50, [0.50]*4)[0] == 0.0
assert margin(0.30, [0.50]*4)[0] == -0.4000      # a real negative margin

assert p_family(0.1042, 0)   == 0.0              # pre-registered
assert p_family(0.1042, 6)   == 0.4832           # six post-hoc tests
```

PART 7 — WHAT WOULD FALSIFY THE INSTRUMENT, AND WHAT IT CANNOT DO

The instrument would be shown wanting if (i) two Navigators running the same frozen features and the same frozen nulls returned different Margins on the same object — that would make it a measure of the Navigator; (ii) the known-answer objects came out wrong — 24-TET at M = 0.000 (it must, by M230-E), and the Moon at a negative Margin; (iii) its Margins failed to order a set of objects whose depths are already established independently — the 24-cell should outrank 24-TET, and the anyon candidate of run 11 should outrank both. None of these has been run.

What it cannot do, stated once: it cannot tell you that Ω42 is true, it cannot rank traditions or thinkers against one another, and it cannot convert a placement into a finding. Those were never its job. Its job is to make one sentence checkable at a glance: "this object's structure exceeds its look-alikes' by this much, on these declared features, against these declared controls, observed under this degree of independence." Everything else at the Aperture is yours.
