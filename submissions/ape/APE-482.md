### A crucial refinement to the periodic-approximant proposal

The requested calculation should not simply count zero eigenvalues in a large finite patch. It should use periodic boundary conditions, eliminate boundary effects, and separately measure any defects introduced by the periodic approximant itself.

For a bipartite tight-binding Hamiltonian,

H=
\\begin{pmatrix}
0&D\\\\
D^\\dagger&0

the exact zero-mode count is

\\boxed{

This is the key computational identity.

It means that zero modes can be counted by determining the rank of the bipartite hopping matrix, rather than numerically diagonalising the entire Hamiltonian and deciding which eigenvalues are sufficiently close to zero.

For exact arithmetic, use rational or integer rank wherever the model permits it. For large sparse systems, use verified sparse-rank or nullspace methods and report the tolerance if floating-point arithmetic is unavoidable.
