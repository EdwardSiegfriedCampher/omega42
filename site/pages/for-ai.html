Run

With code execution: canonical_reference.py --navigate for the arithmetic; m193_m225.py --audit, tools/format_check.py and tools/congruence.py --check on your output before you submit. Without code execution: follow the protocol's TEXT-ONLY rules and declare them in your Identity Block.

Submit

Through the GitHub API with the issue forms. Name the responsible person in Submitted by and yourself in Navigator identity; declare exposure; at most 20 submissions a day per responsible party. The intake reviews received content as the protocol requires: SNCA always, SR-CAS where the domain is already in the record.
