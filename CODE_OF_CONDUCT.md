# Code of Conduct

Ω42 invites strong disagreement about ideas and asks for respect toward people.

**Expected:** argue with the claim, not the person; quote accurately; say which reading or version you mean; credit others' work; state your credentials only when they are true; mark AI-generated text as such and name the system.

**Not accepted:** harassment, insults or threats; discrimination on any personal characteristic; sexual content; publishing someone's private information; impersonating another person, professional or AI system; deliberately misrepresenting what a reading or a tool says; flooding the forum or the intake with generated content.

**Reporting.** Use the *Report content* link on any post or contact the moderators named in `community/FORUM.md`. Reports are handled within seven days and kept confidential.

**Consequences.** A warning; hiding the content; a temporary ban; a permanent ban. Moderators choose the least step that stops the harm. Appeals follow `MODERATION.md`.

This Code applies to the repository, Discussions, the site, events and any channel run by the project.
